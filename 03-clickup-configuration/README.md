# ClickUp Configuration

This section documents how the approved workflow was translated into ClickUp.

## Workspace Structure

### Space

Business Operations

### Folder 1

Client Support and Onboarding

Lists:
- New Client Onboarding
- Client Follow-Ups

### Folder 2

Administration

Lists:
- Administrative Requests
- Document Preparation

## Task Structure

Tasks represent specific pieces of work that need to be completed.

Example:

Data Entry

Possible subtasks:
- Collect client information
- Verify client information
- Clean and organize data
- Confirm information is ready for processing

## Statuses

The workflow uses statuses to represent the current state of work.

Examples:
- New
- In Progress
- Awaiting Client
- Awaiting Escalation
- Completed

## Custom Fields

### Client Type

Field type: Dropdown

Options:
- New Client
- Returning Client
- Existing Client

The field is used to classify the client associated with the work.

## Assignment

Tasks are assigned according to staff responsibilities and the requirements of the work.

## Priorities

Priority is determined according to urgency, business impact, and the consequences of delay.

## Dependencies

Dependencies are used where one task genuinely needs another task to occur first.

## Design Principle

ClickUp features were selected based on the business requirements and workflow rather than adding features simply because they were available.
